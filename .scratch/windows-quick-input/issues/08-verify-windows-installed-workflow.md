**Blocked by:** 03 在外部 Edge 和 Chrome 显式复制片段、04 回填 AtlasOS 编辑器和内嵌网页、05 从独立窗口搜索并插入已保存的片段、06 录制、修改并清除系统快捷键、07 向原终端会话插入片段

## Windows 安装版记录

- `307e660` 在 Windows 11 x64 上通过生产构建和 NSIS 打包。独立注册的安装版与标准包的可执行文件、应用归档和原生助手 SHA-256 一致。Windows 的既有 0.0.23 安装仍保留原注册信息。
- 经典记事本、AtlasOS 便签、Markdown、内嵌网页和两种终端模式均跑过实际系统片段键与窗口键。桌面 Edge、Chrome 明确复制后手动粘贴原文。四种系统剪贴板格式均由独立接收程序粘贴验型。设置创建／编辑／删除、托盘、重启、退出释放、双屏和系统双 Ctrl 钩子均实测。
- 跨应用切窗有一条安装版失败用例。支持的原生 Edit 中按住片段快捷键，切到记事本再松手，复制提示会抢走记事本焦点。中文输入法候选回车也仍未在原生候选窗中得到验证。完整的版本、正文、每种控件的结果、复现和构建命令见[安装版验收报告](../../../docs/WINDOWS_QUICK_INPUT_QA.md)。

## 最终复验

- 最终安装版包含 `280400f`，已集成于 `7fe062f`。按住直达键切走、确认后切走，以及面板最小化时其他应用接管前台，都能取消写入并保留新前台。编辑器同步格式化、终端延迟应答、来源页面重新加载、快捷键录制与显式粘贴均已复测。91 个测试文件中的 726 项测试及生产构建通过。
- 本工单只余微软拼音的真实候选回车。系统文本服务在已获得焦点的安装版搜索页面上返回 `0x80004005`，未激活微软拼音。Chromium 组词事件与普通确认的验证均已通过。故保留 `awaiting-verification`，详见[最终安装版复测](../../../docs/WINDOWS_QUICK_INPUT_QA.md#最终安装版复测)。
