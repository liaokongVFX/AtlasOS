# 03: 回填 Edge 和 Chrome 网页中的原输入框

**What to build:** 用户在 Windows 桌面版 Edge 或 Chrome 编辑网页时，可以用片段快捷键或快捷输入窗口向原输入框插入文字。沿用固定片段即可演示这张工单。

**Blocked by:** 01 在记事本原位置插入一条固定片段

**Status:** ready-for-agent

- [ ] 在 Edge 和 Chrome 各用一个含两个输入框和一个多行编辑框的页面，分别用片段快捷键和窗口确认触发。光标位于文本中部时插入，存在选区时只替换选区，另一输入框和浏览器地址栏保持原内容。
- [ ] 在支持的多行控件核对中文、表情、缩进、制表符、连续空行和末尾换行。表单不会因窗口中确认选择而提交，焦点不会因正文中的制表符跳至其他控件。
- [ ] 在确认前或确认与写入之间，主动切窗、切换标签页、替换或移除原输入框。已失效的选择不能写入新控件；需要用户介入时可主动复制片段。
- [ ] 实测自动插入后原剪贴板仍可粘贴。分别记录两个浏览器的真实文字结果，必测的正常可编辑场景必须完成自动插入；手动复制只用于验证失效和不支持的场景。
