# 03: 在外部 Edge 和 Chrome 显式复制片段

**What to build:** 用户从 Windows 桌面版 Edge 或 Chrome 的网页输入框按片段快捷键后，看到对应片段的「复制片段」操作。通过快捷输入窗口选择片段时也保留选择并提供复制。用户自行决定是否复制以及向哪里粘贴。

**Blocked by:** 01 在记事本原位置插入一条固定片段

**Status:** ready-for-agent

- [ ] 在真实 Edge 和 Chrome 的网页输入框分别验证片段直达和窗口确认。两种入口均显示所选片段和复制操作，页面中原输入框以及另一输入框的内容均保持原样。
- [ ] 打开提示、取消提示或主动切走后，剪贴板内容及其格式保持原样。回车确认搜索选择或按住片段键均不会被视为同意复制。
- [ ] 明确点击「复制片段」后，可将中文、表情、缩进、制表符、连续空行和末尾换行按原样粘贴到多行网页编辑区。
- [ ] 在两个浏览器的独立测试配置中记录实际结果。外部浏览器的复制策略不影响记事本及 AtlasOS 内嵌网页的原目标插入行为。
