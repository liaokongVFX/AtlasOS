# 06: 录制、修改并清除系统快捷键

**What to build:** 用户可以在设置中更改窗口快捷键，并为任意片段录制一个可用的系统快捷键。即使 AtlasOS 在托盘中，按键也能打开窗口或直接插入对应片段。

**Blocked by:** 01 在记事本原位置插入一条固定片段、02 在设置中管理本机快捷语片段

**Status:** ready-for-agent

- [ ] 初次窗口键是 Ctrl+Alt+Space；每条片段初始未绑定。分别录制一个功能键和一个组合键，清除后重启仍保持未绑定。单独的普通字母、数字、空格、回车、Tab 以及系统保留的 F12 都有明确校验反馈。
- [ ] 窗口键、片段键和自定义画布键按规范化后的按键双向排重，提示能辨认冲突的动作；外部软件占用时报告系统注册失败。录制已绑定的键不会同时执行旧动作。
- [ ] 修改、交换或删除片段绑定后，新映射立即生效，已释放的按键可再使用。长按一次只执行一次。模拟注册失败或保存失败，原设置和原有效绑定继续工作。
- [ ] 启动时若其他软件先占用了某个已配置的键，保留配置并指出不可用项，其他绑定照常工作。关闭翻译或隐藏到托盘时本功能继续工作；退出 AtlasOS 后按键可由其他应用注册。
- [ ] 用两条正文不同的片段和记事本，分别演示录制、直达、改键和清除。窗口键则打开快捷输入窗口，不额外插入文字。
