# 06: 录制、修改并清除系统快捷键

**What to build:** 用户可以在设置中更改窗口快捷键，并为任意片段录制一个可用的系统快捷键。即使 AtlasOS 在托盘中，按键也能打开窗口或直接插入对应片段。

**Blocked by:** 01 在记事本原位置插入一条固定片段、02 在设置中管理本机快捷语片段

**Status:** resolved

- [x] 初次窗口键是 Ctrl+Alt+Space；每条片段初始未绑定。分别录制一个功能键和一个组合键，清除后重启仍保持未绑定。单独的普通字母、数字、空格、回车、Tab 以及系统保留的 F12 都有明确校验反馈。
- [x] 窗口键、片段键和自定义画布键按规范化后的按键双向排重，提示能辨认冲突的动作；外部软件占用时报告系统注册失败。录制已绑定的键不会同时执行旧动作。
- [x] 修改、交换或删除片段绑定后，新映射立即生效，已释放的按键可再使用。长按一次只执行一次。模拟注册失败或保存失败，原设置和原有效绑定继续工作。
- [x] 启动时若其他软件先占用了某个已配置的键，保留配置并指出不可用项，其他绑定照常工作。关闭翻译或隐藏到托盘时本功能继续工作；退出 AtlasOS 后按键可由其他应用注册。
- [x] 用两条正文不同的片段和记事本，分别演示录制、直达、改键和清除。窗口键则打开快捷输入窗口，不额外插入文字。

## Comments

- 实现提交 `282574a`。窗口与片段快捷键随应用启动注册。设置的串行保存先保留新键，写入成功后切换动作并释放旧键。系统拒绝注册或设置写入失败时，撤销本次保留的键。退出时只释放本功能的绑定。
- 本机 19 项测试覆盖旧设置、规范化与双向动作冲突、系统保留键和普通打字、交换及删除绑定、注册与磁盘失败回滚、录制已绑定键，以及清除后重启。设置支持直接按键和粘贴组合键名称，方便输入已由其他应用截获的组合。
- 在独立 Windows 桌面上，以正常启动设置运行构建后的 Electron 和系统记事本。另一个进程先占用默认窗口键，设置显示不可用，原配置保留。通过托盘设置录制 F10 与 Ctrl+Alt+B，录制已绑定的 F8 时显示冲突片段名称；关闭翻译并将画布隐藏到托盘后，两条正文分别正确插入。F8 按住并重复超过 5 秒只插入一次；组合键先松修饰键、先松主键时均等待全部释放。窗口键只打开选择窗口。
- 将 F8 改为 F7 后旧键可重新注册，F7 能插入原片段；清除窗口键和另一条片段键后，重新启动保持未绑定。通过托盘退出后，验证器可注册刚释放的 F7。本机脚本见 `tests/hotkeys06/native.test.py electron`，安装包整体验证由工单 08 记录。
