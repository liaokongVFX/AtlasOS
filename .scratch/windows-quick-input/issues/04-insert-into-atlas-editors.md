# 04: 回填 AtlasOS 编辑器和内嵌网页

**What to build:** 用户从便签、Markdown 编辑区或浏览器节点触发快捷输入后，两种入口都会把片段插入原来的编辑区域。一次画布上打开多个节点也能找到正确的目标。

**Blocked by:** 01 在记事本原位置插入一条固定片段

**Status:** resolved

- [x] 在便签、Markdown 和内嵌网页的可编辑控件中逐一验证两种入口。已有选区被替换，光标在文字中部时保留前后文，确认的回车不会进入正文。
- [x] 在便签和 Markdown 中撤销插入可恢复原内容。重新插入、保存并重开画布后能读到正确的内容；网页表单可以感知新值并使用自身的撤销行为。
- [x] 同一画布打开两个同类编辑器以及两个网页输入框，检查只更新原编辑区域。关闭节点、导航网页或切换标签令原目标失效时，按已确定的取消或手动复制行为处理。
- [x] 验证中文、表情、原有空白和多行正文；自动插入后原剪贴板仍可粘贴。内嵌网页本身不能借用快捷输入向其他窗口写入文字。
