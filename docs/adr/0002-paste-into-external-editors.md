# Windows 外部应用按可识别的输入目标使用系统粘贴

普通网页和许多桌面编辑器共用一个窗口句柄来承载多个字段。AtlasOS 用 Windows UI Automation 记录取得焦点的字段，以及控件公开的选区。片段快捷键和搜索确认都在触发键松开、原字段重新获得焦点并通过核验后，将片段原文写入系统剪贴板，再发送一次 Ctrl+V。由目标应用执行粘贴，因此能使用它自己的选区替换、富文本处理和撤销机制。

用户选择让片段留在剪贴板，供目标应用异步读取。Windows 接受粘贴按键后，AtlasOS 结束当前请求；应用仍可按自己的规则过滤文字或拦截粘贴。密码框、只读控件和无法确认的目标继续提供手动复制。AtlasOS 自带编辑器、终端以及标准 Windows 编辑控件沿用直接插入，保留原剪贴板。

部分自绘应用只向 Windows 公开有键盘焦点的窗口或面板。此时按原窗口粘贴：助手保留原进程、窗口和焦点句柄，提交前重新核对前台窗口和辅助功能元素。若应用在同一窗口内自行切换会话或移动光标，文字会进入该窗口当时的输入位置。已识别为只读、密码、非编辑控件的目标，以及失效的字段或选区，继续使用各自原有的判断。

窗口级粘贴对单行和多行片段直接生效。片段快捷键与搜索窗口共用这一规则，首次使用也可直接粘贴。已知外部终端提供手动复制，AtlasOS 终端按当前会话的括号粘贴状态处理多行输入。
