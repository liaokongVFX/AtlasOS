# 01: 在记事本原位置插入一条固定片段

**What to build:** 用户在 Windows 记事本中编辑文字时，可以直接触发一条固定片段，也可以按 Ctrl+Alt+Space 唤起一个可聚焦的最小窗口，按回车把片段插回原处。这张工单用固定测试片段验证回填能力，作为后续接入用户片段的第一个可运行版本。

**Blocked by:** None (can start immediately)

**Status:** resolved

- [x] 在真实记事本的文本中部放置光标，两种触发方式都只插入一次。选中一段文字后重复操作，只有该选区被替换。确认选择的回车不会追加到正文。
- [x] 使用含中文、表情、制表符、前后空格、空行和末尾换行的固定片段，在多行编辑区逐字核对结果，并验证一次编辑可撤销。
- [x] 让剪贴板预先包含图片或文件列表，再通过两种方式插入文字。原内容在其他应用中仍可按原类型粘贴。
- [x] 面板打开后按 Esc 或主动切窗会取消。若确认时原控件已关闭、只读、权限不足或无法核验，保留选择并提供「复制片段」，只有用户点击后才改写剪贴板。
- [x] 按住触发键、连续回车或在确认与提交之间切窗，均不会重复插入或写入另一个目标。部分写入或结果未知时提示检查原处，停止自动重试。
- [x] 在 Windows 记录首次唤起和最小安装版启动的实测结果。固定片段与测试用直达键只用于验证，用户的片段列表以实际保存的设置为准。

## Comments

- 实现提交 `ef5aae7`。Windows 原生助手在启动时就绪，捕获编辑控件与选区，用一次可撤销的替换提交文字。运行 AtlasOS 时显式传入 `--quick-input-test` 才会注册本工单的测试窗口键和直达键 `Ctrl+Alt+F9`。
- 在有独立前台的临时 Windows 桌面，用系统自带的经典记事本、多行 Edit 和新 AtlasOS 测试配置验收。开发构建与 NSIS 打包目录中的 `AtlasOS.exe` 均通过直达／弹窗 × 中部光标／选区四种组合。每次逐字核对中文、表情、制表符、首尾空格、空行及末尾换行，重复触发键和确认键均只插入一次，每次一次撤销均恢复原文。
- 打包版本在关闭自动更新检查的测试配置中，冷启动到主窗口可见为 1.591 秒，首次窗口热键到获得焦点为 0.349 秒，复用窗口为 0.022 秒。Esc 与主动切窗均取消；将实际控件设为只读，或在确认前关闭记事本，窗口均保留所选片段并显示复制按钮。各次自动插入和降级前后的 Windows 剪贴板序列号相同。
- 仍待验证图片和文件列表跨应用粘贴、权限边界、确认到提交间的切窗、部分写入或结果不明，以及从安装器安装后启动。此轮仅检查剪贴板序列号，未改动用户剪贴板。NSIS 已生成安装器与 blockmap；生成更新元数据时 electron-builder 未能从工作树的 `.git/config` 识别 origin，命令以错误结束。工单 08 将验证最终安装包。
- `npm run build`、窗口选择的本机 Vitest 和 `npm run verify:no-tests` 通过。本机可复跑入口为 `tests/quick-input/native.test.py`、`tests/quick-input/palette.test.tsx`；Windows 打包目录的实测日志在同目录 `result.txt`。

## 0.0.26 安装版复验

- 从 NSIS 隔离安装后启动，经典记事本四种光标／选区组合、单次撤销、重复键、Esc、主动切窗、控件只读／关闭均通过。冷启动至画布可见为 1.488 秒，首次窗口键至取得焦点为 0.348 秒，复用为 0.022 秒。使用保存的片段和自定义按键。
- 两种入口触发只接受一个字符的原生控件时均提示检查原处，重复 Enter 不重试。低完整性助手无法更改中完整性控件。在确认键按下与松开之间切窗，两个控件都保持原文。另发现按住直达键切窗再松开会抢回焦点，已记录在安装版报告。
- 首轮以记事本插入前后的剪贴板序列号和独立窗口站的终端跨进程粘贴验型为据。
- 最终安装版 `7fe062f` 通过真实记事本的两种入口 × 光标／选区、原文与撤销复验。首轮发现的直达键按住时切窗抢回焦点已修正；确认后切窗和面板最小化时第三方应用获焦也都保留新前台。
- 经用户授权，一次写入测试文件列表后重复以上四种记事本操作。每次在独立进程中实际粘贴得到 CF_HDROP、唯一的测试文件路径与预期文件内容，剪贴板序列号一直保持为 34。见[安装版实测记录](../../../docs/WINDOWS_QUICK_INPUT_QA.md#最终安装版复测)。
