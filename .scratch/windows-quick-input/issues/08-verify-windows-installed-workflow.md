# 08: 在 Windows 安装版验收完整流程

**What to build:** 使用 Windows 安装版，从创建片段到向真实应用插入，按实际结果记录可用范围和失败行为；同时验证 AtlasOS 托盘运行、退出与重新启动时的体验。

**Blocked by:** 03 在外部 Edge 和 Chrome 显式复制片段、04 回填 AtlasOS 编辑器和内嵌网页、05 从独立窗口搜索并插入已保存的片段、06 录制、修改并清除系统快捷键、07 向原终端会话插入片段

**Status:** ready-for-agent

- [ ] 构建并安装 Windows 版本，从冷启动开始在设置中创建和修改片段。用自定义片段键和窗口搜索分别验证记事本、桌面 Edge 和 Chrome、AtlasOS 便签与 Markdown、内嵌网页以及终端规定的模式。
- [ ] 逐项记录应用版本、控件、两种入口、期望正文和实际结果。记事本和 AtlasOS 编辑区以实际自动插入为通过条件，外部 Edge/Chrome 以用户明确复制且手动粘贴得到原文为通过条件，覆盖选区替换和可表达该内容的多行控件。控件失效、只读、权限受限、终端模式未知单列降级结果。
- [ ] 用文本、图片、文件列表和富文本分别占用剪贴板。完成自动插入后到其他应用粘贴验证原格式；覆盖用户在面板打开期间复制新内容的情况。
- [ ] 覆盖目标失效、主动切窗、同窗换输入框、连按和长按、中文输入法候选回车、多屏、双 Ctrl 翻译、托盘触发及退出后按键释放。核对其他应用未收到片段，剪贴板只在用户选择复制时被改写。
- [ ] 记录本地针对性测试、构建和安装版实测结果。任何承诺自动插入的目标只能复制、写错目标、重复写入或破坏剪贴板时，保持该验收项未通过并列出可重现的操作。
