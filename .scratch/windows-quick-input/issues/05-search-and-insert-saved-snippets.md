# 05: 从独立窗口搜索并插入已保存的片段

**What to build:** 用户按窗口快捷键即可在原输入目标所在屏幕搜索已保存的片段，用键盘选择并将完整原文插回。可用记事本从头到尾演示，主画布在托盘中时也能使用。

**Blocked by:** 01 在记事本原位置插入一条固定片段、02 在设置中管理本机快捷语片段

**Status:** resolved

- [x] 每次唤起使用同一个独立窗口，清空上次查询，聚焦搜索框，并选中第一条结果。空查询按设置顺序展示；有查询时名称命中优先于仅正文命中，同级保持原顺序。
- [x] 每行显示名称、单行正文预览和已有的片段快捷键。在长正文的预览被截断时，回车仍按实际保存的完整正文插入。新增、修改、删除后再次打开即可看到最新列表。
- [x] ↑/↓ 切换选项，Enter 确认一次，Esc 取消。中文输入法组词、选词时，方向键和回车首先作用于输入法。空列表、无结果、过期请求或已删除片段都不会插入其他条目。
- [x] 焦点持续留在搜索框，辅助技术能读出当前选项。按产品深色与中英文规范核对窗口；在多屏和托盘场景检查窗口位于原目标显示器的工作区。
- [x] 主动切窗取消，控件失效时可从失败提示主动复制原文。快速再次唤起、连续按 Enter 以及关闭前一次窗口，都不会向旧位置或新目标重复写入。确认双 Ctrl 翻译在此窗口中不会误触发外部选区捕获。
