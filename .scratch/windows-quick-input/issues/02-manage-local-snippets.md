# 02: 在设置中管理本机快捷语片段

**What to build:** 用户在「设置 → 快捷输入」中新增、修改、删除有名称和正文的快捷语片段。所有画布共用这份列表，关闭并重启 AtlasOS 后仍能接着使用。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 旧版本的设置首次打开时得到空片段列表、默认窗口键 Ctrl+Alt+Space；旧画布、语言和终端配置均可正常读取。
- [ ] 新建的片段默认没有片段快捷键。修改名称或正文后仍是列表中的原条目；允许两个不同片段有相同正文，编辑或删除其中一个只影响选中的条目。
- [ ] 保存含中文、表情、首尾空格、制表符、连续空行和末尾换行的正文。重新打开、切换画布及重启后，列表顺序和文字内容与保存时一致。
- [ ] 编辑片段期间从其他入口修改一项无关设置，两项更改都能保留；模拟写入失败时，界面可见错误，重启后仍能读取此前成功保存的版本。
- [ ] 设置页面遵循 AtlasOS 的现有深色规范和中英文文案习惯。可以仅通过设置界面完成所有验收。
