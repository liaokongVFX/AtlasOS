# 01: 在记事本原位置插入一条固定片段

**What to build:** 用户在 Windows 记事本中编辑文字时，可以直接触发一条固定片段，也可以按 Ctrl+Alt+Space 唤起一个可聚焦的最小窗口，按回车把片段插回原处。这张工单用固定测试片段验证回填能力，作为后续接入用户片段的第一个可运行版本。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 在真实记事本的文本中部放置光标，两种触发方式都只插入一次。选中一段文字后重复操作，只有该选区被替换。确认选择的回车不会追加到正文。
- [ ] 使用含中文、表情、制表符、前后空格、空行和末尾换行的固定片段，在多行编辑区逐字核对结果，并验证一次编辑可撤销。
- [ ] 让剪贴板预先包含图片或文件列表，再通过两种方式插入文字。原内容在其他应用中仍可按原类型粘贴。
- [ ] 面板打开后按 Esc 或主动切窗会取消。若确认时原控件已关闭、只读、权限不足或无法核验，保留选择并提供「复制片段」，只有用户点击后才改写剪贴板。
- [ ] 按住触发键、连续回车或在确认与提交之间切窗，均不会重复插入或写入另一个目标。部分写入或结果未知时提示检查原处，停止自动重试。
- [ ] 在 Windows 记录首次唤起和最小安装版启动的实测结果。固定片段与测试用直达键只用于验证，用户的片段列表以实际保存的设置为准。
