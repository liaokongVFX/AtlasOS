# 07: 向原终端会话插入片段

**What to build:** 用户从 AtlasOS 终端调用快捷输入时，片段写入当时取得焦点的会话。单行正文可直接输入，多行正文只有在原会话此刻支持括号粘贴时才自动插入。

**Blocked by:** 01 在记事本原位置插入一条固定片段

**Status:** resolved

- [x] 用两个终端会话分别验证片段直达和弹窗确认。单行片段只进入原会话；确认键不会自动执行命令。原会话已关闭或被替换时取消写入。
- [x] 在已启用括号粘贴的会话验证多行片段，包括仅在末尾含一个换行的片段。检查完整正文作为一次粘贴交给终端前台程序。
- [x] 在括号粘贴关闭或模式无法确认时，多行输入提供手动复制；自动路径不得将正文中的换行逐个投递给 shell。切换模式后按提交时的实际模式判断。对无法确认粘贴语义的外部终端同样提供多行复制。
- [x] 在直接插入、取消和显示复制选项后检查原剪贴板内容。只有用户实际选择「复制片段」时，剪贴板才成为片段正文。
